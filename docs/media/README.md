# README media

Captured on 2026-10-31 from the running `artifacts/win-x64/DesktopPet.exe` on Windows. These show the development preview for 1.5; the published release may look different. They are actual screen captures, not generated images or UI mockups.

- `desktop-companion.png`: the cat and a slime keepsake on the desktop.
- `battle-hub.png`: the Battle Mode hub.
- `battle-setup.png`: custom fight preparation, using the existing Set 1 preset.
- `boss-fight.png`: a custom fight against the Slime King.
- `desktop-pet-intro.mp4`: 32 seconds, 1280 × 720, H.264, 24 fps, no audio. First 8 seconds use the desktop and hub screenshots; the remaining 24 seconds are a real recording of preparation and a custom fight. Titles and a development-preview label were added during editing. No drag/throw footage is included.
- `battle-preview.gif`: a seven-second, reduced-resolution excerpt of the video for the README preview.

Only the monitor containing the pet was captured for these files. The browser on the other monitor and the Windows taskbar are excluded. The custom fight saves no adventure progress or records; its result panel was closed afterward and the cat returned to the desktop. User preferences were not overwritten.

The Windows wallpaper visible in these captures belongs to its respective rights holder and is not covered by the project's MIT license. Original project code and artwork retain the license documented in the repository root.

These assets are committed locally. GitHub playback/layout has not yet been checked; the MP4 is linked as a file rather than relying on an embedded video player.
